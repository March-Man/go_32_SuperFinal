# TODO Scheduler

## Описание проекта
Веб-сервер для планирования задач (аналог TODO-листа). 
Приложение позволяет создавать, редактировать, удалять задачи и отмечать их выполненными. 
Поддерживает периодические задачи с различными правилами повторения (ежедневно, ежегодно, по дням недели и месяца). 
Сервер написан на Go, использует SQLite для хранения данных и поддерживает JWT-аутентификацию.

## Выполненные задания со звёздочкой
- Переменные окружения: реализована поддержка `TODO_PORT`, `TODO_DBFILE`, `TODO_PASSWORD`.
- Поиск задач: реализован поиск по подстроке (в заголовке и комментарии) и по конкретной дате через параметр `search`.
- Аутентификация: если при запуске задана переменная `TODO_PASSWORD`, 
  доступ к API защищён JWT-токеном. Без неё аутентификация отключена.
- Docker: создан `Dockerfile` для сборки и запуска приложения в контейнере.

## Инструкция по локальному запуску
1. Убедитесь, что установлен Go (версия 1.26 или выше)
2. Склонируйте репозиторий и перейдите в папку проекта
3. Запустите сервер (go run .)
4. Запуск всех тестов (go test ./tests)
5. Сборка образа (docker build -t scheduler:v1 .)
6. Запуск контейнера (docker run -d \
  -p 7540:7540 \
  -e TODO_PORT=7540 \
  -e TODO_DBFILE=/app/scheduler.db \
  -e TODO_PASSWORD=12345 \
  -v $(pwd)/scheduler.db:/app/scheduler.db \
  scheduler:v2)
7. Перейти по ссылке `http://localhost:7540/`
8. Вводим пароль (12345)
9. Убеждаемся, что все работает правильно
10. Засчитываем работу (`я на это надеюсь)))`)
